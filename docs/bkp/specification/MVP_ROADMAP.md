# EdApex Master MVP Roadmap

## Phase 1: Core Foundation & Scaling (Weeks 1-4)
**Goal**: Deploy the planet-scale technical foundation.
*   **Infrastructure**: Establish the Rust crate workspace and PostgreSQL 16 schema with RLS.
*   **Identity**: Execute JWT/MFA stateless auth and the deterministic PBAC Engine.
*   **Domain**: Deploy the Polymorphic Entity repository and Recursive Academics system.
*   **UI**: Setup the unified Next.js + Tauri shell for Web and Desktop.

## Phase 2: High-Fidelity Education Operations (Weeks 5-8)
**Goal**: Achieve feature parity with InfixEdu across all core educational workflows.
*   **Students**: Complete lifecycles (Admission, Promotion, Guardian linking).
*   **Academics**: Syllabus tracking, Lesson plans, and Timetable routing.
*   **Attendance**: Real-time subject/daily attendance with NATS notifications.
*   **Exams**: Online/Offline assessment setup and Grade-sheet processing.

## Phase 3: Financial Integrity & Domain Services (Weeks 9-12)
**Goal**: Deploy the precise financial and logistics engines.
*   **Finance**: Unified Ledger implementation for Fees, Wallets, and Payroll.
*   **Logistics**: Library cataloging, Transport route optimization, and Dormitory allocations.
*   **Reporting**: PBAC-isolated administrative and financial dashoards.

## Phase 4: Autonomic Intelligence & Self-Evolution (Weeks 13-16+)
**Goal**: Activate the "Self-Evolving" and "Beyond the Horizon" AI layer.
*   **Orchestration**: Deploy the Level 1 Executive HMAS agent.
*   **Federation**: Activate the Federated Learning Node for global benchmarking.
*   **Innovations**:
    *   Deploy **Emotional State Analysis** (Cognitive engagement monitoring).
    *   Activate **Autonomic Sustainability Intelligence** (Smart Building energy syncing).
    *   Enable **Synthetic Peer Personas** for students.
*   **Evolution**: Close the loop by enabling tool optimization via `ai.evolution_log`.
