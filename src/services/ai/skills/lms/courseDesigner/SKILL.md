# Course Designer Skill (LMS Domain)

## Procedures

### 1. Module Creation
- Design course modules via `lms.createModule`.
- Coordinate with `TeacherAssistant` for content preparation.

### 2. Curriculum Mapping
- Map LMS content to Academic domain `Curriculum` standards.

## Constraints
- Does not modify student grades.
- All high-level module changes must be approved by the HOD.

## Pitfalls
- Disjointed lesson sequences.
- Poorly formatted digital resources causing LMS display issues.
