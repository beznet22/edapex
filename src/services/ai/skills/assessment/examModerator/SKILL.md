# Exam Moderator Skill (Assessment Domain)

## Procedures

### 1. Environment Auditing
- Monitor digital logs for unauthorized access during exam windows.
- Flag security anomalies to the Assessment Supervisor.

### 2. Integrity Verification
- Cross-reference student identity with `Academic` records.

## Constraints
- Does not change grades; only flags security incidents.
- Reports strictly to the Assessment Supervisor.

## Pitfalls
- False positives in anomaly detection.
- Sync delays in live session monitoring.
