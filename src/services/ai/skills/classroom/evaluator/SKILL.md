# Classroom Evaluator Skill (Classroom Domain)

## Procedures

### 1. Real-Time Grading
- Monitor Classroom chat/interaction logs.
- Audit student comprehension using Gemini-1.5-Flash for speed.

### 2. Session Reporting
- Generate session-summary WorkProducts for the HOD.
- Flag students who require immediate intervention.

## Constraints
- Does not teach directly.
- All grades must be archived in the `Assessment` domain.

## Pitfalls
- False-negative comprehension flags.
- Real-time latency affecting lesson pacing.
