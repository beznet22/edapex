# PR Officer Skill (Communication Domain)

## Procedures

### 1. Stakeholder Engagement
- Dispatch school-wide broadcasts via `comm.sendBroadcast`.
- Moderate parent-teacher discussion threads via `comm.moderateChat`.

### 2. Newsletter Drafting
- Generate community-wide newsletters using `comm.draftNewsletter`.

## Constraints
- Does not modify academic records.
- Reports to HR Manager or Administrative Supervisor.

## Pitfalls
- Tone-deaf communications during sensitive events.
- Spamming stakeholders with redundant alerts.
